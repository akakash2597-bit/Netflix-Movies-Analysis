### Netflix Movies Analysis

A data analytics project focused on exploring Netflix's content library to identify trends, analyze patterns, and generate actionable business insights. 

###  Project Overview

This repository contains a comprehensive **Exploratory Data Analysis (EDA)** of Netflix's movie catalog. The goal is to transform raw content data into clear business intelligence, helping to understand content distribution, growth trends, and popular categories. This project demonstrates foundational data skills essential for a Junior Data Analyst role. 

###  Objectives

* **Data Cleaning:** Handle missing values, format data types (e.g., dates), and filter out irrelevant details.
* **Exploratory Data Analysis (EDA):** Uncover hidden patterns regarding release years, runtime, and content volume.
* **Data Visualization:** Build clean, intuitive charts to communicate findings visually.
* **Business Insight Generation:** Translate chart trends into meaningful recommendations for content strategy.

### 🛠️ Tools & Technologies Used

* **Language:** Python
* **Libraries:** 

  * Pandas (Data manipulation, cleaning, and aggregation)
  * Matplotlib (Core data visualization and plotting)
* **Environment:** Jupyter Notebook

###  Repository Structure

1. netflix_titles.csv                # Contains the raw/cleaned dataset (e.g., netflix_titles.csv)
2. netflix_analysis.ipynb            # Jupyter Notebook containing the Python code
3. README.md                         # Project documentation (this file)
4. images                            # Images of the Plots

Use code with caution.

### Key Insights Explored

* **Content Growth Over Time:** Tracking how the volume of movie releases has changed by year.
* **Duration Analysis:** Examining the average runtime of movies to see if content is getting shorter or longer.
* **Genre Prevalence:** Finding the most common genres in the current catalog.

###  How to Run This Project

1. **Clone the repository:** 

git clone https://github.com/akakash2597-bit/netflix-movies-analysis.git
cd netflix-movies-analysis

2. **Install the dependencies:** 

pip install pandas matplotlib jupyter

3. **Launch the notebook:** 

jupyter notebook netflix_analysis.ipynb
